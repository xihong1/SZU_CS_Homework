# NovaLang 类型系统设计文档

## 一、类型概览

NovaLang采用**静态强类型**系统。所有变量的类型在编译时确定，且必须通过 `@类型` 注解显式标注。

### 1.1 基本类型

| 类型 | 关键字 | 字面量示例 | 说明 |
|------|--------|-----------|------|
| 整型 | `int` | `42`, `0`, `-7` | 整数 |
| 浮点型 | `float` | `3.14`, `2.0` | 浮点数 |
| 字符串 | `string` | `"hello"`, `"a"` | 字符串字面量，支持转义 |
| 布尔型 | `bool` | `true`, `false` | 布尔值 |
| 空类型 | `void` | 无 | 仅用于函数返回类型 |

### 1.2 复合类型

| 类型 | 语法 | 示例 |
|------|------|------|
| 数组 | `类型[大小]` | `int[5]`, `float[10]` |
| 函数类型 | `返回类型(参数类型列表)` | `int(int,int)`, `void()` |

### 1.3 类型表示法

在NovaLang中，类型通过两种方式表达：
- **声明时**：`int a`, `int a[5]`, `fn(int) func -> ...`
- **使用时**：`a@int`, `a[0]@int`, `a@int[5]`

这种设计将类型检查从声明时刻扩展到使用时刻，提升了错误定位的可观测性。

## 二、类型兼容性规则

### 2.1 严格匹配原则

NovaLang采用**严格类型匹配**（Strict Type Matching），不允许隐式类型转换：

- `int` 与 `float` **不兼容**
- `string` 与任何数值类型 **不兼容**
- `bool` 与其他类型 **不兼容**

### 2.2 赋值兼容性

赋值语句 `lvalue = expr` 要求左值类型与右值表达式类型**完全一致**：

```
int a
a@int = 42        // OK: int = int
a@int = 3.14      // ERROR: int = float (类型不匹配)
```

### 2.3 运算符类型约束

| 运算符类别 | 运算符 | 允许的类型 | 结果类型 |
|-----------|--------|-----------|---------|
| 算术 | `+`, `-`, `*`, `/` | int, float | 与操作数相同 |
| 算术 | `%` | int | int |
| 关系 | `<`, `<=`, `>`, `>=` | int, float | bool |
| 相等 | `==`, `!=` | int, float, string, bool | bool |
| 逻辑 | `&&`, `||` | bool | bool |
| 一元逻辑非 | `!` | bool | bool |
| 一元负号 | `-` | int, float | 与操作数相同 |

二元运算符要求左右操作数类型一致。

### 2.4 函数调用兼容性

函数调用需满足：
1. **参数个数匹配**：实参个数 = 形参个数
2. **参数类型匹配**：每个实参类型与对应形参类型一致
3. **被调用者必须为函数**：变量不能当作函数调用

### 2.5 返回类型兼容性

`return` 语句的表达式类型必须与函数声明的返回类型一致：
- 若函数返回 `void`，不能有 `return expr`
- 若函数返回非 `void`，必须有 `return expr` 且类型匹配

## 三、类型转换

NovaLang**禁止**C风格强制类型转换（如 `(int)x`）。类型转换必须通过对象方法显式进行：

| 方法 | 调用方式 | 源类型 | 目标类型 |
|------|---------|--------|---------|
| `toFloat()` | `x@int.toFloat()` | int | float |
| `toInt()` | `x@float.toInt()` | float | int |

## 四、作用域规则

### 4.1 作用域层次

NovaLang支持三级嵌套作用域：

```
全局作用域 (global)     -- 函数声明
├── 函数作用域 (function) -- 参数 + 局部变量
│   └── 块作用域 (block)   -- if/while 块内变量
```

### 4.2 变量遮蔽

内层作用域可以声明与外层同名的变量，内层变量将**遮蔽**外层变量。遮蔽仅限于不同作用域层级。

### 4.3 声明规则

- 同一作用域内**不允许**重复声明同名变量或函数
- 变量必须**先声明后使用**
- 函数支持**前向引用**（先使用后定义）

## 五、语义错误类型

| 错误类型 | 说明 | 示例 |
|----------|------|------|
| `UNDECLARED` | 使用未声明的变量或函数 | `y@int = 1` (y未声明) |
| `REDECLARED` | 同一作用域重复声明 | `int x; int x;` |
| `TYPE_MISMATCH` | 类型不兼容 | `int a = "hello"` |
| `ARG_COUNT_MISMATCH` | 函数调用参数个数错误 | `f(1)` 但 f 需要2个参数 |
| `ARG_TYPE_MISMATCH` | 函数调用参数类型错误 | `f("s")` 但形参为 int |
| `NOT_A_FUNCTION` | 将非函数当作函数调用 | `x->(1, 2)` 但 x 是变量 |
| `RETURN_TYPE_MISMATCH` | 返回值类型不匹配 | `fn(int) f ->: return "str"` |
