ABOUT VDS
========================================================================
VDS is a universal Integrated Development Environment for developers and database administrators. It simplifies the development and management of Vastbase G100 Database in both traditional and Cloud deployments. VDS is built on the Eclipse Rich Client Platform (RCP), taking advantage of the RCP framework for building and deploying native GUI applications. For more information on VDS, refer to the VDS User Manual.
