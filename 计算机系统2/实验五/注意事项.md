由于是在Windows环境下运行代码，所以要对代码A进行一些必要的修改：

1.  头文件替换：

    - 移除了UNIX/Linux系统的头文件

    - 添加了 #include <windows.h> 用于Windows API

2.  计时函数替换：

    - 将 struct timeval time1, time2 替换为 LARGE_INTEGER frequency, start, end

    - 使用 QueryPerformanceFrequency()和QueryPerformanceCounter() 替代 gettimeofday()

    - 计算执行时间的方式改为Windows高精度计时器的方式

3.  命令行参数处理：

    - 移除了命令行参数检查

    - 使用 scanf() 来获取用户输入的矩阵大小

    - 添加了用户友好的提示信息

4.  内存管理：

    添加了 free() 调用来释放动态分配的内存，避免内存泄漏
