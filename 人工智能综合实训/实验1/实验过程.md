## 三、实验原理

### 3.1 ResNet50 简介

ResNet（Residual Network）由何恺明等人于 2015 年提出，核心思想是引入**残差连接（skip connection）**：

```
输出 = F(x) + x
```

其中 `x` 为输入，`F(x)` 为若干卷积层学习到的残差映射。残差连接解决了深层网络训练时的梯度消失 / 退化问题，使得网络可以堆叠到 50 层、101 层甚至更深而不损失精度。

ResNet50 共 50 层，由若干 Bottleneck 残差块堆叠而成，结构大致为：

- 初始卷积 + 最大池化；
- 4 个 Stage，每个 Stage 包含多个残差块（[3, 4, 6, 3] 个 Bottleneck）；
- 全局平均池化 + 全连接层，输出 1000 维（对应 ImageNet 的 1000 类）。

### 3.2 迁移学习

从零训练一个 50 层的 ResNet 需要海量数据与算力。迁移学习的思想是：模型在 ImageNet（约 1400 万张、1000 类）上已经学到了丰富的通用视觉特征（边缘、纹理、形状、物体部件等），这些特征对大多数图像任务都适用。因此我们**直接复用预训练权重**，无需重新训练即可完成识别。

### 3.3 猫狗识别的实现思路

预训练 ResNet50 输出 1000 个类别的概率，其中：

- **第 151 ~ 268 类**：各种犬类（如「京巴犬」「柯基」「金毛」等）；
- **第 281 ~ 285 类**：各种猫类（如「虎斑猫」「波斯猫」「暹罗猫」等）。

因此，只需把模型输出的 1000 维概率向量按这两个区间**分别求和**，即可聚合得到「猫」「狗」两类各自的置信度：

```
P(狗) = Σ prob[151:269]
P(猫) = Σ prob[281:286]
```

再对两者做归一化，即可得到直观的二分类结果。

### 3.4 Gradio

Gradio 是一个轻量级的 Python 库，用几行代码即可把任意函数包装成可交互的网页应用，无需编写前端代码。本实验用 `gr.Interface` 将 `predict` 函数与「图片上传」「标签输出」两个控件绑定。

## 五、核心代码说明

完整代码见同目录下的 `height.py`，关键部分如下：

### 5.1 加载预训练模型

```python
weights = models.ResNet50_Weights.IMAGENET1K_V1
model = models.resnet50(weights=weights)
model.eval()
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = model.to(device)
```

- 使用 `IMAGENET1K_V1` 版本的预训练权重；
- `eval()` 关闭 Dropout / BatchNorm 的训练行为；
- 自动检测并使用 GPU，否则退回 CPU。

### 5.2 猫狗类别区间

```python
DOG_IDX = list(range(151, 269))   # 犬类：ImageNet 第 151~268 类
CAT_IDX = list(range(281, 286))   # 猫类：ImageNet 第 281~285 类
```

### 5.3 图像预处理

```python
transform = transforms.Compose([
    transforms.Resize(256),       # 短边缩放到 256
    transforms.CenterCrop(224),   # 中心裁剪到 224×224
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225]),
])
```

预处理必须与 ImageNet 训练时保持一致（224×224 输入、相同均值/方差标准化），否则识别精度会大幅下降。

### 5.4 推理与聚合

```python
with torch.no_grad():
    outputs = model(input_tensor)
probs = torch.softmax(outputs[0], dim=0).cpu()

cat_prob = float(probs[CAT_IDX].sum())
dog_prob = float(probs[DOG_IDX].sum())
total = cat_prob + dog_prob
cat_prob, dog_prob = cat_prob / total, dog_prob / total
return {"猫": cat_prob, "狗": dog_prob}
```

- `torch.no_grad()` 关闭梯度计算，节省显存、加速推理；
- `softmax` 将 logits 转为概率；
- 按区间求和后归一化，得到「猫 / 狗」两类概率。

### 5.5 Gradio 界面

```python
demo = gr.Interface(
    fn=predict,
    inputs=gr.Image(type="pil", label="上传图片"),
    outputs=gr.Label(num_top_classes=2, label="识别结果"),
    title="猫狗识别器（ResNet50）",
    examples=[["./1.jpg"], ["./dog2.jpg"]],
)
demo.launch()
```

## 六、实验结果与分析

在本地对两张测试图片运行，结果如下：

| 测试图片 | Top-1 原始类别 | P(猫) | P(狗) | 判定结果 | 是否正确 |
| --- | --- | --- | --- | --- | --- |
| 1.jpg | Pekinese（京巴犬） | ≈ 0.00 | ≈ 1.00 | 狗 | ✅ |
| dog2.jpg | Pembroke（柯基犬） | ≈ 0.00 | ≈ 1.00 | 狗 | ✅ |

**分析：**

1. 两张图片均以接近 100% 的置信度被判定为「狗」，且 Top-1 类别分别为京巴犬、柯基犬等具体犬种，说明预训练模型对犬类特征具有很强的判别能力。
2. 由于预训练权重在 ImageNet 上已充分收敛，本实验**无需任何训练**，仅在 CPU 上单次推理耗时约 0.015 ~ 0.6 秒，满足实时识别需求。
3. 该方法的局限：它只能区分「猫 / 狗」这两大类（本质是对 1000 类输出的二次聚合），对猫的具体品种、以及猫狗之外的其它动物无法进一步区分；若要精确到品种，需在其基础上对最后几层进行微调（Fine-tuning）。

## 七、实验总结

本实验通过复用 ImageNet 预训练的 ResNet50，结合「类别区间聚合」技巧，用较少的代码实现了一个简单、可交互的猫狗识别器，并用 Gradio 快速搭建了网页界面。实验加深了对以下知识点的理解：

- 残差网络与残差连接的设计思想；
- 迁移学习「预训练 + 复用」的通用范式；
- 图像预处理（缩放、裁剪、标准化）对模型精度的重要性；
- 使用 Gradio 将深度学习模型快速产品化的工作流。

## 八、可能的改进方向

1. 使用 Kaggle「Dogs vs Cats」数据集对 ResNet50 进行微调，将最后一层替换为 2 类输出，可得到更聚焦、更精确的二分类模型。
2. 增加图片增强（翻转、裁剪等），提升模型鲁棒性。
3. 在 Gradio 中增加实时摄像头输入、批量图片上传等功能，提升交互体验。
